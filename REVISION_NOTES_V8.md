# Broadway Academy redesign preview — v8

## Header
- Restored a genuinely sticky global header. It remains visible while scrolling and switches to its compact state after scrolling begins.
- The sticky positioning is applied to the shared header mount point so the injected header is not constrained by its parent height.
- SEND and Easy Read sticky controls continue to sit immediately beneath the live compact header.

## Dining
- Added Broadway photography to the redesigned Dining page using hot-linked public assets.
- Retained the in-house catering content, Arbor/cashless information, breakfast/break/lunch structure, dietary information and farm-to-kitchen link.
- Removed prototype/design commentary from the public copy.

## Bringing content into the redesign
- Rebuilt all 15 subject curriculum pages with substantive local curriculum content rather than a button back to the legacy page.
- Expanded Admissions, Governance, Ofsted, Statutory Information, Community Centre, Community pricing, Function Hire, Fitness Suite, Inter-faith Work, 360 Tour, Jobs, Sixth Form, News, Interventions, Privacy and Cookies.
- Reduced reliance on legacy-page links; external actions are now mainly reserved for live forms, official services, recruitment feeds and downloadable documents.
- Restructured Policies so the complete policy directory is visible in the redesign instead of every policy name linking back to the legacy index.

## Results

- Added 2025/26 results to search, the exams hub, sitemap and related-results navigation.
