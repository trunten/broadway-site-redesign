# Broadway Academy redesign preview — v6

- Removed the repeated Academy motto heading from the homepage welcome section.
- Removed the redundant footer Useful links strip.
- Footer term information now shows Autumn, Spring and Summer together for the relevant academic year.
- The date-selection logic now chooses the academic year rather than a single current/next term.
- Removed the extra All term dates link from the term panel; the Families column retains the normal Term dates & calendar link.
- The global page header now scrolls away with the page instead of remaining sticky.
- Compact header styling is retained during the initial scroll transition.
- The shared header-height variable now tracks only the visible portion of the header, so SEND, Easy Read and sticky side navigation do not retain an empty offset after the header has scrolled away.
